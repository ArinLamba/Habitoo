# Habitoo

Habitoo is organized as a monorepo.

## Apps

- `apps/web` - Next.js web app
- `apps/mobile` - Expo mobile app

## Packages

- `packages/core` - shared business logic for future web/mobile reuse

## Commands

Run commands from the repository root:

```bash
npm run dev
npm run dev:mobile
npm run typecheck
npm run lint
```
